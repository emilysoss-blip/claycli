The account agent

One Clay account agent writes the prep above for every account that passes the step-4 gate. It replaces the step-5 Claygent. It reads the account's audience record, contacts and signals, then searches the web, and fills twelve fields in one run.

Build it in the workflow

  1. Create a bare agent node after the step-4 gate.
  2. Run clay workflows nodes create-account-agent <workflowId> <nodeId> --name "Eightfold - New HR Leader Account Prep".
  3. Set the prompt below on the node, then set the task list in a separate update.
  4. Check that accountId wired itself from the accounts trigger.
  5. Add a write-to-Audiences node after it with entityType: ACCOUNT.
