Four guide commands that would break the build

Checked against clay-run/agent-plugins at a813258. Citations in eightfold/clay/guide_corrections.md.

  1. Enrich-node fields are at $.result.<field>. The guide's $.toolResult.result path resolves to nothing, and graph validate will not catch it.
  2. Signal --input uses segmentIds. The guide's {"audiences":[...]} matches neither the input shape nor the read-back shape input.audiences {segmentIds, entityType}.
  3. runs test --trigger <csv> --limit 10 runs every row. Use clay workflows triggers csv run <triggerId> --limit 10, and put rows 11–60 in a new file for the 50-row pass, because --limit has no offset.
  4. An unwired CSV trigger accepts csv run, then fails every row. Check the wiring with graph get before the first run.

The guide asks for #1 and #2 to be copied into the Vim guide as corrections. They should not be.
